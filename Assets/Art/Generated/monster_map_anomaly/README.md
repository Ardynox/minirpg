Original anomaly-themed monster pack for the mini-RPG project.

This pack is intentionally original and is not a copy of RimWorld or RimWorld Anomaly art.

Files in this folder:
- `monster_anomaly_eye_cluster.png`
- `monster_anomaly_flesh_bloom.png`
- `monster_anomaly_tentacle_maw.png`
- `monster_anomaly_void_hound.png`

Output specs:
- Single sprite: `256x256`
- Directional sheet counterpart: `Assets/Art/Generated/monster_map_iso8_anomaly/*_8dir.png`
- Directional sheet size: `256x2048` with 8 stacked facing frames

Suggested use:
- Prototype hostile anomaly encounters
- Temporary concept art while waiting for a final art pass
- Direct wiring into `Data/entity_render.json` as texture-based monster renders
