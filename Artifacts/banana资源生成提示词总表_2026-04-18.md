# Banana 资源生成提示词总表

> 生成：2026-04-18  
> 目标：以 Gemini 验证过的"等距 2.5D / 3/4 俯视正交 / 半写实 / 低饱和 / 柔和阴天"风格，对 `Assets/Art/` 下的全部可替换资源出一张可直接复制粘贴给 Banana（Gemini 2.5 Flash Image / Nano Banana）的 prompt 表。

---

## 0. 总则

### 工作流（每条资源）
1. 按下表复制 **Prompt** 列整段发给 Banana。
2. 拿到图后按 **重命名为** 列的精确文件名保存。
3. 覆盖到 **原路径** 列的位置。`.png.import` 文件**不要动**。
4. 如果 Banana 输出尺寸/背景不对，看 §0.3 补救话术。

### 0.1 会话策略
- **每个大类新开会话**，避免风格污染（地面 / 建筑 / 物品 / 角色 / 怪物 / 立绘 / 特效 各自独立）。
- 每个会话开头**先贴 §0.2 风格基线**做一次锚定，再进入逐行 prompt。
- 若某张感觉飘了，追加：`keep the exact style of the previous output`。

### 0.2 风格基线（每个新会话开头粘贴一次）
```
I am building a classic 2.5D isometric RPG. For this entire session, ALL images must lock in the following visual style:

- Perspective: isometric 2.5D game asset, 3/4 top-down orthographic view, NO perspective distortion
- Style: grounded semi-realistic, muted color palette, low saturation, worn/weathered feel
- Lighting: soft overcast daylight, no harsh sun, no cast shadows on ground
- Finish: clean readable game texture, orthographic game asset feel
- HARD NEGATIVES: no anime, no cartoon, no chibi, no bright saturated colors, no glossy plastic, no cinematic lighting, no bloom, no concept art, no splash art, no watercolor, no heavy outlines, no text, no watermark, no background scene

Acknowledge this style and wait for my first subject. When I send a subject, output ONE PNG at the exact pixel size I specify, isolated on a fully transparent background (alpha=0). If transparency fails, fall back to a solid neutral gray background for easy keying.
```

### 0.3 常见补救话术
| 问题 | 贴回去的一句 |
|---|---|
| 背景不是透明 | `remove background, export as PNG with fully transparent alpha, no shadow plate, no gray backdrop` |
| 尺寸不对 | `crop to square and resize to exactly 256x256 pixels` |
| 风格飘了 | `match the exact style, palette and lighting of the previous image` |
| 加了多视图 | `only a single view, one object, not a turnaround sheet` |
| 多余装饰/文字 | `remove all text, labels, watermarks, UI elements, captions` |
| 加了投影板 | `no ground plane, no shadow disk under the object` |

- [ ] 同类放一起平铺看，风格和饱和度没有跳变
- [ ] `.png.import` 没有被覆盖/删除
- [ ] 角色类的脚点（feet）能对齐到画布下端 ~85% 处，不会漂浮或陷地
