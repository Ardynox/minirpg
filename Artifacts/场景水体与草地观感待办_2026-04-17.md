# MiniRPG 场景水体与草地观感待办（2026-04-17）

> **触发**：当前用户反馈“游戏场景中的水和草地不太满意”。
> **性质**：有边界的一次性视觉待办，按仓库约定放 `Artifacts/`，不新开泛用 `TODO.md`。
> **迁移规则**：若其中某项进入正式开发批次，再迁到 `Docs/重构路线图.md` 或对应模块局部文档。
> **当前假设**：先按“更自然、更有层次、减少塑料感和重复感”收敛，不先扩成整套地表重做。

## 目标

- 让草地和水体看起来更像“可生活的世界表面”，而不是单张贴图平铺。
- 提升地表可读性：玩家一眼能分清草地、水体、岸边过渡，而不需要靠 glyph 或 hover。
- 先做小闭环：只动当前水/草资源、映射和过渡，不顺手扩大到整套 biome overhaul。

## 当前不满意点拆解

### 水体

- [ ] 水面可能过平、过死，像“蓝色贴片”而不是水。
- [ ] 岸边过渡不够自然，草地/泥地/水体之间像硬切。
- [ ] 如果 `TopTile = stone` 参与了当前等距显示，会让水面读感进一步失真。
- [ ] 缺少“浅/深/边缘”的层次信息，玩家看不出这是浅水、深水还是仅仅一种地板。

### 草地

- [ ] 大面积草地平铺感强，重复纹样容易被看出来。
- [ ] 草地颜色和明度可能过于单一，缺少“活”的感觉。
- [ ] 草地与泥地、道路、水边的交界不够柔和。
- [ ] 高草 overlay 已有，但当前密度、分布或底图搭配可能还没形成“自然长出来”的观感。

## 第一批可执行待办

### A. 先确认现状，不盲改

- [ ] 在同一场景截 3 组基线图：纯草地、草地靠水边、大片水域。
- [ ] 标出当前最刺眼的问题是“颜色”、“重复”、“边缘过渡”还是“体素顶面错误”。
- [ ] 单独验证等距视角里水面是否真的受 `TopTile = stone` 影响；先确认事实再动映射。

### B. 水体小闭环

- [ ] 给 `water` 准备 2 到 3 个候选底图，不只盯 `blends_natural_02_6.png` 一张。
- [ ] 若当前顶面读感确实有误，修正 [`Data/terrains.json`](../Data/terrains.json) / [`Module/Render/VoxelTilePathResolver.cs`](../Module/Render/VoxelTilePathResolver.cs) 的水面顶图路径。
- [ ] 补一版“岸边过渡”方案：
  - 优先先用现有 `PZ_Tiles` 里的自然 blend 片拼出来；
  - 不够再考虑补画 1 小组专用 shoreline tile。
- [ ] 若静态图仍显得假，再评估是否加极轻量的水面动画/闪光，而不是直接上复杂 shader。

### C. 草地小闭环

- [ ] 重新挑选或混用 `blends_natural_01_21/22`，避免“一种绿铺到底”。
- [ ] 调整 `grass_patch` 的抽样密度和使用范围，让高草成为“点缀层”，不是随机噪声层。
- [ ] 草地边缘优先处理两类交界：
  - 草 -> 水
  - 草 -> 路/泥
- [ ] 如果当前 `tile_grass_top.png` / `tile_grass_side.png` 偏塑料或偏亮，单独出一轮替换稿，不和 2D 地表混在一起改。

## 验收口径

- [ ] 玩家不看 UI 也能一眼分清：这里是草地、那里是水、边上是岸。
- [ ] 视野里连续 5x5 以上草地时，不会第一眼看到明显重复拼贴。
- [ ] 水边不再像“蓝色地砖贴到绿色地砖旁边”。
- [ ] 角色站在草地和水边时，视觉重点仍是场景，不会被刺眼高饱和地表抢走。
- [ ] 改动后不破坏现有 terrain id、碰撞和生成逻辑，只调整视觉表现。

## 暂时不做

- [ ] 不顺手重做整套 biome。
- [ ] 不把所有自然地表一次性全部重画。
- [ ] 不为了水草观感问题，把渲染层整体重构一遍。
- [ ] 不新增一个“全项目美术 TODO 总表”。

## 推荐落地顺序

1. 先做水面顶图/岸边过渡的事实核对。
2. 再做草地底图与高草 overlay 的搭配调整。
3. 最后才考虑轻量动画、shader 或新画资源。

## 备注

- 这份待办本身不直接推进可玩闭环，但它帮助把“场景观感不满意”收敛成后续可以逐条落地的小任务。
- 如果后面确认“水”比“草”问题更明显，优先级应先给水体，因为它更影响场景识别和氛围建立。
