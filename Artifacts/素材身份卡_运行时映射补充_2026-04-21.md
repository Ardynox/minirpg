## 1. 天气资源 id（B1.2 vs `WeatherFxController`）

身份卡 B1.2 列 6 个文件名：`rain` / `fog` / `dust` / `lightning` / `sand_cover` / `wet_gloss`。

`Module/Render/WeatherFxController.cs` 中 `WeatherAssetIds` 另含 **`snow_cover`、 `ice_gloss`、 `snow`**。生成与验收以代码常量为准；主表可视为「气候叠层扩展」。

## 2. B7 大部位占位图命名（B7.4 vs `PlaceholderUiIconCatalog`）

身份卡 B7.4 示例文件名偏「解剖标签」式；**游戏内实际路径**由 `PlaceholderUiIconCatalog.PathForLimb` + `ResolveLimbPlaceholderSuffix` 决定，磁盘当前为 **10 张**：

| 运行时后缀（`limb_<suffix>.png`） | 说明 |
| --- | --- |
| `head` | 头 |
| `neck` | 颈 |
| `torso` | 躯干 |
| `left_arm` / `right_arm` | 左/右臂（非身份卡写的 `arm_left`） |
| `left_leg` / `right_leg` | 左/右腿（非身份卡写的 `leg_left`） |
| `eyes` | 眼区（合并双眼，非单 `eye`） |
| `heart_lungs` | 心+肺合并示意（非拆成 `heart` + `lung` 两张） |
| `hands` | 手/指相关 |

若将来要改成与身份卡逐字一致的文件名，需同步改 `ResolveLimbPlaceholderSuffix` 与已有 PNG 命名。

## 3. B9 装备 overlay（投影后叠图）

- **路径 / 命名**：`EquipmentOverlayPaths` → `Assets/Art/Generated/equipment_overlays/equip_{weapon|cloak|helmet}_*_<dir>.png`。  
- **`<dir>` 顺序**：与 `DirectionalSpriteHelper.ResolveDirectionRow` 行 0..7 一致，为 **s, sw, w, nw, n, ne, e, se**（非按字母排序）。  
- **启用条件**：某一装备 **8 张全存在** 才对该类走 PNG；否则该类仍由 `MapSpriteRuntimeFactory` 在 64×64 规范帧上程序绘制。  
- **画布**：身份卡写 128；当前实现为 **256×256**（与 `ExportSize` 一致），较小资源会最近邻放大。
