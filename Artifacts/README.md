# Artifacts

这个目录只放一次性分析、巡检、预览图和实验产物。
默认不要把它当成代码入口或长期文档入口。

## 这里适合放什么

- 日期型扫描和审计
- 资源预览图、临时导出图、验证截图
- 只对当前问题或当前分支有价值的对比报告

## 这里不该放什么

- 当前稳定架构说明
- 团队默认约定
- 长期维护的开发文档

这些内容应该回到 `Docs/` 或复杂目录自己的短 `README`。

## 保留与清理约束

- 一次性报告写完即用，**合并进主线之后默认可以删**。
- 约束：Artifacts 里的文件**自合并日起 30 天内**视情况保留；超过 30 天的产物如无人在当前改动中引用，应在下一次清理窗口删除。
- 清理窗口：每次对 `Docs/` 做结构性更新、或路线图推进到新批次时，一并清一次 `Artifacts/`。
- 不要把"历史价值"作为保留理由。`git log` + PR 描述才是历史档案；`Artifacts/` 只承担"当下"。
