# 社交系统 (Social Module)

## 概述

管理角色间的好感度、关系标签和社交互动。好感度是非对称的（A 对 B 的看法可以和 B 对 A 不同），影响 AI 行为和心情系统。

## 文件清单

| 文件 | 职责 |
|------|------|
| `Core/Social/SocialModels.cs` | 数据模型：`RelationEntry`、`SocialState`、`SocialInteractionDef` |
| `Core/Social/SocialModule.cs` | 核心逻辑：好感度查询/修改、社交互动、关系判定 |

## 数据模型

```
GameState
  └── SocialState
        ├── Relations: Dict<"fromId:toId", RelationEntry>
        │     ├── Opinion: int (-100 ~ 100)
        │     ├── Tags: HashSet<string>  // friend, rival, lover, family...
        │     └── LastInteractionTurn: int
        └── SocialCooldowns: Dict<actorId, lastSocialTurn>
```

## 核心 API

```csharp
// 好感度
SocialModule.GetOpinion(state, "player", "npc1");       // → int
SocialModule.AdjustOpinion(state, "player", "npc1", 10); // 加减
SocialModule.SetOpinion(state, "player", "npc1", 50);    // 直接设置

// 关系标签
SocialModule.AddTag(state, "player", "npc1", "friend");
SocialModule.HasTag(state, "player", "npc1", "friend");  // → bool
SocialModule.RemoveTag(state, "player", "npc1", "friend");

// 关系判定
SocialModule.IsFriend(state, from, to);  // opinion >= 50
SocialModule.IsRival(state, from, to);   // opinion <= -50

// 社交互动（带冷却，每 10 回合一次）
SocialModule.TryInteract(state, initiatorId, recipientId); // → List<GameEvent>

// 查询
SocialModule.GetRelationsOf(state, actorId);     // A 对所有人的关系
SocialModule.GetRelationsToward(state, actorId); // 所有人对 A 的关系
```

## 社交互动流程

```
SocialModule.TryInteract(initiator, recipient)
  ├── 冷却检查（10 回合间隔）
  ├── SelectInteraction()
  │     ├── 过滤：当前好感度在 [MinOpinion, MaxOpinion] 范围内
  │     └── 加权随机选择
  ├── 双向调整好感度
  │     ├── initiator → recipient: +InitiatorOpinionChange
  │     └── recipient → initiator: +RecipientOpinionChange
  ├── 更新冷却和时间戳
  └── 产出 GameEvent("social_interaction")
```

## 与其他系统的集成

| 系统 | 集成方式 |
|------|----------|
| AI 行为 | `SimpleBrain.BuildIdleDecision()` 中检查附近友好 Actor，调用 `SocialModule.TryInteract()` |
| 心情/Thought | 好感度变化时生成 Thought（如"和朋友聊天 +5 心情"） |
| 队伍招募 | `PartyModule.TryRecruit()` 可以检查好感度门槛 |
| 事件系统 | 社交事件可以触发关系变化（如"争吵"降低好感度） |
| 对话系统 | `DialogRuleEngine` 条件中可以加入好感度判断 |

## 扩展指南

- **社交互动 JSON**：GPT 可以批量写 `SocialInteractionDef` 数据
- **关系衰减**：在 `TurnModule` 中定期调用衰减逻辑，好感度缓慢归零
- **关系面板 UI**：读取 `GetRelationsOf()` 渲染关系列表
- **好感度影响交易价格**：在 `TradeModule` 中根据好感度调整折扣
