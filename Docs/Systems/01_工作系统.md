# 工作系统 (Job Scheduler)

## 概述

让 NPC 自动领取和执行工作任务：搬运材料、建造设施、制作物品、补充燃料、搬运产出。这是从"单人动作游戏"转向"殖民地管理"的关键基础设施。

## 文件清单

| 文件 | 职责 |
|------|------|
| `Core/Job/JobScheduler.cs` | 任务调度器：扫描 JobBoard、为工人分配最优任务 |
| `Core/Job/JobExecutor.cs` | 任务执行器：根据 ticket 类型执行具体动作（移动/拾取/交付/制作） |
| `Core/Job/JobBehaviorModule.cs` | AI 行为模块：插入 AIDispatcher 行为链 |

## 数据模型

工作系统复用已有的 `WorkTicket` 和 `JobBoardState`（定义在 `Core/Data/FacilityModels.cs`）。

```
GameState
  └── JobBoardState
        ├── Tickets: Dictionary<string, WorkTicket>   // 所有待执行任务
        └── LastRebuildTurn: int                       // 上次重建回合
```

### WorkTicket 类型

| 类型 | 说明 | 优先级 |
|------|------|--------|
| `DeliverConstructionMaterial` | 搬运建材到蓝图设施 | 50 |
| `ConstructFacility` | 建造设施 | 60 |
| `RepairFacility` | 修理损坏设施 | 40 |
| `RefuelFacility` | 补充燃料 | 30 |
| `ProduceRecipe` | 执行制作配方 | 20 |
| `HaulFacilityOutput` | 搬运产出到 Stockpile | 10 |
| `SupplyFacilityInput` | 供应原材料 | 20 |

## 调度流程

```
每回合 AIDispatcher.TickAll()
  └── 对每个 BrainId == "domain_worker" 的 Actor
        └── JobBehaviorModule.TryExecute()
              ├── 检查：是工人？空闲状态？附近无威胁？
              ├── 查找已预留任务 → 验证有效性
              ├── 无任务 → JobScheduler.FindBestTicket()
              │     ├── EnsureTicketsUpToDate()（每 5 回合重建）
              │     ├── 过滤：距离 ≤ 30、未被他人预留、能力匹配
              │     └── 评分：priority × 100 - 距离
              ├── TryReserve() 预留任务
              └── JobExecutor.Execute() 执行一步
                    ├── 背包无所需物品 → 移动到物品位置拾取
                    ├── 未到设施旁 → 寻路移动
                    └── 到达 → 执行工作动作
```

## 执行器行为

`JobExecutor.Execute()` 是一个多步状态机，每次调用执行一步：

1. **搬运类任务**（Deliver/Refuel/Supply）：检查背包 → 没有则去拾取 → 有了则移动到设施 → 交付
2. **建造/修理**：移动到设施旁 → 执行建造/修理
3. **制作**：移动到设施旁 → 每回合减少 `WorkRemaining` → 完成时消耗输入产出输出
4. **搬运产出**：到设施拿物品 → 移动到 Stockpile → 放下

## 集成点

- **AIDispatcher**：在 `NeedBehavior` 之后、`Brain.Decide()` 之前插入 `JobBehaviorModule`
- **AIProfiling**：`AIDispatchMetrics` 新增 `JobBehaviorMs` 字段
- **Brain 注册**：`AIDispatcher` 静态构造函数注册 `"domain_worker"` → `SimpleBrain`（工人空闲时复用简单 AI）

## 如何让 NPC 成为工人

```csharp
actor.BrainId = WorkBrainIds.DomainWorker; // "domain_worker"
```

设置后该 NPC 会自动参与工作调度。战斗状态或附近有威胁时暂停工作，回退到 SimpleBrain 行为。

## 扩展指南

- **新增任务类型**：在 `WorkTicketType` 枚举加值 → `JobScheduler` 加 `Emit*Tickets` → `JobExecutor` 加 `Execute*` 分支
- **工作优先级 UI**：读取 `WorkTicket.Priority`，允许玩家调整
- **技能影响效率**：在 `JobExecutor.ExecuteProduce` 中根据 `Actor.Experiences` 调整 `WorkRemaining` 减少量
