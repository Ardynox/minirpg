# 事件系统 (Storyteller)

## 概述

RimWorld 风格的事件调度器。根据殖民地状态（回合数、队伍规模、威胁历史）动态调节事件频率和类型，让游戏始终保持张力。

## 文件清单

| 文件 | 职责 |
|------|------|
| `Core/Event/IncidentDef.cs` | 事件定义数据模型 + `IncidentCategory` 枚举 |
| `Core/Event/StorytellerState.cs` | 运行时状态：冷却、延迟队列、历史记录 |
| `Core/Event/IIncidentWorker.cs` | 事件执行器接口 |
| `Core/Event/Storyteller.cs` | 核心调度器：选择 + 触发 + 威胁等级计算 |
| `Core/Event/Workers/BuiltinIncidentWorkers.cs` | 3 个内置执行器 |

## 数据模型

```
GameState
  └── StorytellerState
        ├── LastIncidentTurn: Dict<defId, turn>   // 冷却追踪
        ├── PendingIncidents: List<PendingIncident> // 延迟事件队列
        ├── History: List<IncidentRecord>           // 最近 50 条历史
        ├── ThreatLevel: float                      // 当前威胁等级 0~100
        └── LastCheckTurn: int                      // 上次调度检查回合
```

### IncidentDef 字段

| 字段 | 说明 |
|------|------|
| `Id` | 唯一标识 |
| `Category` | Threat / Neutral / Positive |
| `Weight` | 选择权重 |
| `MinTurn` | 最早触发回合 |
| `CooldownTurns` | 触发后冷却 |
| `MinPartySize` | 最少队伍人数 |
| `ThreatPoints` | 威胁点数（袭击规模） |
| `WorkerId` | 执行器 ID |
| `Params` | 额外参数 |

## 调度流程

```
TurnModule.AdvanceWorld()
  └── Storyteller.Tick()
        ├── ProcessPendingIncidents()  // 触发到期的延迟事件
        └── 每 30 回合检查一次
              ├── UpdateThreatLevel()
              │     ├── 基础 = min(50, turn/100)
              │     ├── + 队伍规模 × 5
              │     └── - 最近威胁事件数 × 10
              ├── CalculateCategoryWeights(threatLevel)
              │     ├── 威胁高 → 更多 Threat 事件
              │     └── 威胁低 → 更多 Positive 事件
              └── SelectIncident()
                    ├── 过滤：MinTurn、冷却、MinPartySize、Worker.CanFire()
                    └── 加权随机选择
```

## 内置事件执行器

| Worker | 说明 |
|--------|------|
| `RaidIncidentWorker` | 在玩家周围 8-12 格生成一波敌人 |
| `WandererJoinIncidentWorker` | 在 5-8 格处生成可招募的友好 NPC |
| `TraderVisitIncidentWorker` | 在地图边缘 15 格处生成商人 |

## 核心 API

```csharp
// 注册事件定义和执行器
Storyteller.RegisterDef(new IncidentDef { ... });
Storyteller.RegisterWorker("raid", new RaidIncidentWorker());

// 强制触发（调试/脚本）
Storyteller.ForceFireIncident(state, "raid_goblin");

// 安排延迟事件
Storyteller.ScheduleIncident(state, "trader_visit", delayTurns: 20);
```

## 扩展指南

- **新增事件类型**：实现 `IIncidentWorker` → `Storyteller.RegisterWorker()` → 写 JSON 定义
- **难度曲线调节**：修改 `UpdateThreatLevel()` 中的公式
- **事件链**：在 Worker.Execute() 中调用 `Storyteller.ScheduleIncident()` 安排后续事件
