# 区域系统 (Zone Module)

## 概述

通用区域管理框架，扩展已有的 `StockpileZone` 为 6 种区域类型。玩家可以在地图上划定区域，NPC 根据区域类型执行对应行为。

## 文件清单

| 文件 | 职责 |
|------|------|
| `Core/Zone/ZoneModule.cs` | 区域管理：创建/删除/查询 + `ZoneDef` 数据模型 + `ZoneType` 枚举 |

## 数据模型

```
GameState
  └── Zones: Dict<string, ZoneDef>
        ├── Id, Name, Type, OwnerDomainId
        ├── Cells: List<ZoneCell>          // 区域包含的格子
        ├── CropId: string                 // 种植区专用
        ├── AllowedAnimalIds: List<string> // 家畜区专用
        ├── AllowedItemIds / AllowedCategories  // 存储区专用
        ├── Priority: int
        └── Enabled: bool
```

## 区域类型

| 类型 | 说明 | NPC 行为 |
|------|------|----------|
| `Stockpile` | 存储区 | 工人搬运物品到此处 |
| `Growing` | 种植区 | 工人在此种植/收获作物 |
| `Animal` | 家畜区 | 动物被限制在此区域 |
| `Forbidden` | 禁区 | NPC 不进入 |
| `Home` | 家区 | NPC 休息/社交的区域 |
| `Dumping` | 垃圾区 | 丢弃不需要的物品 |

## 核心 API

```csharp
// 创建区域
var zone = ZoneModule.CreateZone(state, ZoneType.Growing, "小麦田", DomainIds.Player);
zone.CropId = "wheat";

// 添加/移除格子
ZoneModule.AddCell(zone, 5, 5, 0);
ZoneModule.RemoveCell(zone, 5, 5, 0);

// 删除区域
ZoneModule.RemoveZone(state, zoneId);

// 查询
ZoneModule.GetZonesAt(state, x, y, z);           // 该位置的所有区域
ZoneModule.GetZonesByType(state, ZoneType.Growing); // 所有种植区
ZoneModule.IsForbidden(state, x, y, z);           // 是否在禁区
ZoneModule.IsHome(state, x, y, z);                // 是否在家区
ZoneModule.FindNearestCell(state, ZoneType.Stockpile, fromX, fromY, fromZ);

// 农业集成
ZoneModule.GetEmptyGrowingCells(state); // 需要种植的空格子
```

## 与现有 StockpileZone 的关系

现有 `GameState.StockpileZones` 仍然保留，用于已有的设施系统搬运逻辑。新的 `Zones` 字典是更通用的框架。迁移路径：

1. 短期：两套并存，`JobScheduler` 查 `StockpileZones`，新系统查 `Zones`
2. 中期：将 `StockpileZone` 数据迁移到 `ZoneDef`（Type = Stockpile）
3. 长期：废弃 `StockpileZones`，统一使用 `Zones`

## 与其他系统的集成

| 系统 | 集成方式 |
|------|----------|
| 工作系统 | `JobScheduler` 查询种植区生成种植/收获 ticket |
| 农业系统 | `FarmModule` 通过 `ZoneModule.GetEmptyGrowingCells()` 确定种植位置 |
| AI 寻路 | `SimpleBrain` / `FollowerBrain` 检查 `IsForbidden()` 避开禁区 |
| 渲染 | `TileMapRenderModule` 可以用不同颜色高亮不同类型区域 |

## 扩展指南

- **区域绘制 UI**：鼠标拖拽选择格子 → 调用 `AddCell()` / `RemoveCell()`
- **区域优先级**：多个同类型区域时，按 `Priority` 排序
- **区域过滤器 UI**：存储区的物品过滤器编辑面板
