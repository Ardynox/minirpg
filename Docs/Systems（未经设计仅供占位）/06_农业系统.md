# 农业系统 (Farm Module)

## 概述

种植、生长、收获的完整生命周期。与区域系统（种植区）和工作系统（种植/收获任务）深度集成。

## 文件清单

| 文件 | 职责 |
|------|------|
| `Core/Farm/CropModels.cs` | 数据模型：`CropDef`、`CropInstance`、`CropRegistry` |
| `Core/Farm/FarmModule.cs` | 核心逻辑：种植/生长/收获/枯萎/自动重种 |

## 数据模型

```
GameState
  └── Crops: Dict<"x,y,z", CropInstance>
        ├── CropDefId: string
        ├── X, Y, Z: int
        ├── Growth: int          // 当前生长进度
        ├── Mature: bool         // 是否成熟
        ├── Withered: bool       // 是否枯萎
        └── PlantedTurn: int

CropRegistry (静态)
  └── CropDef
        ├── GrowthTurns: int     // 生长所需回合
        ├── HarvestItemId: string
        ├── HarvestMin/Max: int  // 产出数量范围
        ├── SeedItemId: string
        ├── AutoReplant: bool
        └── Seasons: List<string>  // 适宜季节
```

## 生命周期

```
1. 玩家划定种植区 → ZoneDef.CropId = "wheat"
2. 工人执行种植任务 → FarmModule.Plant(state, "wheat", x, y, z)
3. 每回合 TurnModule.AdvanceWorld()
   └── FarmModule.TickGrowth(state)
         ├── 季节检查 → 不适宜则枯萎
         ├── Growth++ → 达到 GrowthTurns 则 Mature = true
         └── 产出 GameEvent("crop_mature")
4. 工人执行收获任务 → FarmModule.Harvest(state, x, y, z, harvester)
         ├── 随机产出 [HarvestMin, HarvestMax] 个物品
         ├── 物品进入收获者背包（或掉落地面）
         └── AutoReplant → 自动重新种植
```

## 季节系统

简单实现：每 100 回合一个季节。

| 回合范围 | 季节 |
|----------|------|
| 0-99 | spring |
| 100-199 | summer |
| 200-299 | autumn |
| 300-399 | winter |

如果 `CropDef.Seasons` 非空且当前季节不在列表中，作物会枯萎。`Seasons` 为空表示全季节作物。

## 核心 API

```csharp
// 种植
FarmModule.Plant(state, "wheat", x, y, z);  // → FarmActionResult

// 收获（可指定收获者，物品进背包）
FarmModule.Harvest(state, x, y, z, harvester);

// 移除（清理枯萎作物）
FarmModule.Remove(state, x, y, z);

// 查询
FarmModule.GetCropAt(state, x, y, z);       // → CropInstance?
FarmModule.GetMatureCrops(state);            // 所有成熟作物
FarmModule.GetWitheredCrops(state);          // 所有枯萎作物
FarmModule.GetGrowthPercent(crop);           // 0.0 ~ 1.0
```

## 与其他系统的集成

| 系统 | 集成方式 |
|------|----------|
| 回合推进 | `TurnModule.AdvanceWorld()` 调用 `FarmModule.TickGrowth()` |
| 区域系统 | `ZoneModule.GetEmptyGrowingCells()` 查询需要种植的空格子 |
| 工作系统 | 扩展 `WorkTicketType` 加入 `PlantCrop` / `HarvestCrop` 类型 |
| 渲染 | 根据 `GetGrowthPercent()` 显示不同生长阶段的 Tile |
| 天气 | 可扩展：干旱减缓生长、暴雨加速生长 |

## 扩展指南

- **肥料系统**：在 `CropInstance` 加 `FertilizerBonus`，`TickGrowth` 中加速生长
- **病虫害**：随机事件让作物生病，需要喷洒农药
- **灌溉**：检查附近是否有水源设施，影响生长速度
- **作物品质**：收获时根据种植者技能和土壤品质决定物品品质
