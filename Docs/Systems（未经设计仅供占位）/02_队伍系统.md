# 队伍系统 (Party Module)

## 概述

支持玩家控制多个角色，Tab 键切换激活角色，非激活成员由 AI 自动跟随。这是从单角色 roguelike 扩展为殖民地管理的核心改动。

## 文件清单

| 文件 | 职责 |
|------|------|
| `Core/Data/PartyModule.cs` | 队伍管理：招募/解散/切换/查询 + `PartyState` 数据模型 |
| `Core/AI/FollowerBrain.cs` | 跟随者 AI：攻击相邻敌人 → 跟随激活角色 → 空闲 |

## 数据模型

```
GameState
  └── Party: PartyState
        ├── MemberIds: List<string>   // 有序成员列表，[0] = 队长
        ├── ActiveId: string          // 当前接受输入的角色
        └── MaxSize: int              // 最大队伍人数（默认 6）
```

## 核心 API

```csharp
// 初始化（新游戏时调用）
PartyModule.Initialize(state);

// 招募 NPC
PartyModule.TryRecruit(state, "npc_id");  // → PartyActionResult

// 解散（不能解散队长）
PartyModule.TryDismiss(state, "npc_id");

// Tab 切换
PartyModule.CycleActive(state);  // → 返回新激活角色 ID

// 点击头像切换
PartyModule.TrySetActive(state, "npc_id");

// 查询
PartyModule.IsPartyMember(state, actorId);  // 替代 id == state.PlayerId
PartyModule.GetActiveId(state);              // 替代 state.PlayerId（输入路由）
PartyModule.GetActiveActor(state);           // 获取激活角色实体
PartyModule.GetMembers(state);               // 所有成员实体列表
```

## 改造的现有模块

| 模块 | 改动 |
|------|------|
| `TimelineTurnManager.IsPlayerTurn()` | `actor.Id == state.PlayerId` → `actor.Id == PartyModule.GetActiveId(state)` |
| `TimelineTurnManager.SubmitPlayerAction()` | 同上 |
| `TimelineTurnManager.AdvanceAuto()` | 同上 |
| `TimelineTurnManager.CreateDebugSnapshot()` | `IsPlayer` 改为 `PartyModule.IsPartyMember()` |
| `AIDispatcher.TickAllInternal()` | 跳过激活角色（而非跳过所有队伍成员） |
| `AIDispatcher` 静态构造 | 注册 `"party_follower"` → `FollowerBrain` |

## FollowerBrain 行为

非激活的队伍成员使用 `FollowerBrain`，优先级：

1. **攻击相邻敌人**：检查 1 格内的敌对 Actor，选择最强攻击技能
2. **跟随激活角色**：距离 > 2 格时寻路移动
3. **空闲**：距离 ≤ 2 格时原地待命

## 向后兼容

- `PartyState.MemberIds` 为空时，`GetActiveId()` 回退到 `state.PlayerId`
- `IsPartyMember()` 在空列表时视 `state.PlayerId` 为唯一成员
- 旧存档加载后无需迁移，首次调用 `EnsureValid()` 自动修复

## 扩展指南

- **队伍 UI 面板**：读取 `PartyModule.GetMembers()` 渲染头像列表，点击调用 `TrySetActive()`
- **队伍阵型**：扩展 `FollowerBrain` 的跟随逻辑，支持不同阵型偏移
- **队伍共享背包**：在 `InventoryModule` 中加入跨成员物品查询
