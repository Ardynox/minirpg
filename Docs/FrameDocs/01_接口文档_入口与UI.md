# 01 接口文档: 入口与 UI

## 范围与口径

- 范围：`App/Main.cs`、`Module/*`、`Module/Panel/*`、`Module/Render/*`、`Module/Editor/*`
- 排除：自动化测试模块、资源目录编辑器辅助、独立预览控件
- 当前统计：71 个运行时 `.cs` 文件，132 个 `public` 类型
- 目标：说明主入口如何装配 UI/流程模块，以及 UI 层对 Core 的公开协作面

## 重点协作接口

| 接口 / 适配器 | 语义 | 核心成员 | 主要实现 / 使用方 | 架构意义 |
| --- | --- | --- | --- | --- |
| `IGameUI` | UI 子模块访问主入口能力的薄契约 | `AddLog`、`EnterSelection`、`FlushMap`、`Dispatch`、`SubmitPlayerAction`、`HandlePlayerDeath`、`State` | `Main` 实现；`CombatUIModule`、`DialogUIModule`、`TradeUIModule` 使用 | 把子 UI 模块对 `Main` 的依赖压缩为有限入口 |
| `IPanel` | 面板统一行为接口 | `PanelId`、`Visible`、`HandleCommand`、`OnFocus/OnBlur`、`Dirty`、`FlushIfDirty` | 各类 `*PanelModule`、`PanelManager` | 面板焦点、边框、键盘路由的稳定边界 |
| `IAnimatable` | 角色/实体动画的抽象 | `Play`、`PlayOneShot`、`Stop`、`SetFacing`、`Ready` | `FantasyCharacterAnimatable`、`SpineAnimatable`、`TileAnimatable`、`TileMapRenderModule` | 渲染实现可替换，不把业务层绑死到具体动画组件 |
| `ISettingsFlowPanel` | 设置流程中的可见面板最小约束 | `Visible` | `PauseMenuPanelModule`、`SettingsPanelModule` | 把焦点控制与具体面板解耦 |
| `ISettingsFlowFocusHost` | 设置流程的焦点宿主适配器 | `IsFocused`、`SetFocus`、`PushFocus`、`OnPanelClosed` | `PanelManagerSettingsFlowFocusHost` | 用适配器把 `SettingsFlowCoordinator` 连到 `PanelManager` |
| `IPauseMenuOverlay` | 暂停菜单的专用接口 | `Open`、`Close`、`RefreshTexts`、`ActionRequested` | `PauseMenuPanelModule` | 让暂停菜单可被协调器单独驱动 |
| `ISettingsOverlay` | 设置面板的专用接口 | `Open`、`ApplyState`、`HandleKeyInput`、`LanguageChangedRequested` 等 | `SettingsPanelModule` | 统一承接渲染、语言、布局、存档等设置动作 |
| `PanelManagerSettingsFlowFocusHost` | `PanelManager` 到设置流程接口的桥接器 | `SetFocus`、`PushFocus`、`OnPanelClosed` | `SettingsFlowCoordinator` | 明确“设置流程不直接知道 PanelManager”这一层适配 |
