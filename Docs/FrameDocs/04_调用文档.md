# 04 调用文档

## 调用中心

- `Main.Dispatch`：领域事件到日志、HUD、对话、交易、动画、副作用的统一路由中心。
- `TimelineTurnManager`：玩家动作提交与自动回合推进中心。
- `GameSessionModule`：新游戏、切世界、载入、保存、楼层切换的会话中心。
- `TileMapRenderModule`：地图、天气、记忆层、玩家动画与 UI 脏刷新联动中心。

## 启动与组合根

- 入口：`Main._Ready`，随后由 `Main._Process` 持续轮询启动任务。
- 调用者：Godot 场景树。
- 被调者：`GameConfig.Load`、`PresetDB.Load`、`LocalizationService.Initialize/SetLocale`、`DialogPool.Load`、`ResAccess.Load`、`CombatFxRegistry.Load`、`PlayerAppearanceCatalog.LoadProjectCatalog`、`GameSessionModule`、`MenuModule`、`PanelManager`、`InputModule`、`SettingsFlowCoordinator`、`WorldManagerModule`、`MapEditorBarModule`。
- 关键前置条件：`Main` 场景节点已就绪；配置与资源目录可读。
- 状态变更：构造 `_session`、`_menu`、`_panels`、`_inputModule`、`_settingsFlow`、HUD、渲染器与编辑器状态；读入本地设置与语言。
- 事件 / 返回值：子模块按钮事件、设置事件、世界管理器事件、地图编辑事件都在 `_Ready` 中完成接线。
- 副作用：加载配置文件、翻译资源、渲染资源、用户键位与用户数据目录。
- 刷新点：启动轮询完成后进入主菜单；进入游戏时走 `DoEnterGame -> FlushMap`。

## 输入与面板焦点

- 入口：`Main._UnhandledInput` 与 `Main._Input`。
- 调用者：Godot 输入系统。
- 被调者：`PanelHoverChromeService.HandleInput`、`PanelDragService.HandleGlobalInput`、`SettingsFlowCoordinator.HandleKeyInput/HandleMouseInput`、`PanelManager.HandleKey`、`InputModule.HandleKeyInput/HandleMouseButtonInput`、各 overlay `HandleKeyInput`。
- 关键前置条件：先经过忙碌态、确认框、世界管理器、世界设置、存档命名、角色创建、布局编辑、地图编辑、设置流程等一层层 gate。
- 状态变更：切换 `InputFocus`、面板焦点栈、overlay 可见性、布局编辑 / 地图编辑模式。
- 事件 / 返回值：`InputModule` 产生命令字符串；`PanelManager` 把按键映射成 `IPanel.HandleCommand`。
- 副作用：Esc 可关闭 overlay 或当前焦点面板；右键与拖拽改变浮动面板状态。
- 刷新点：面板边框刷新、布局编辑条显示、后续命令进入 `Main.OnCommand`。

## 玩家回合

- 入口：`InputModule.CommandReceived -> Main.OnCommand`，或 UI 子模块通过 `IGameUI.SubmitPlayerAction` 直接提交。
- 调用者：键盘绑定、方向选择、技能条、面板交互。
- 被调者：`Main.SubmitPlayerAction` -> `TimelineTurnManager.SubmitPlayerAction` -> `ActionModule.TryMove/TryCastSkill/TryDig/TryInteract` -> `CombatModule` / `InteractionModule` / `NeedActionModule` / `HealthActionModule` / `SurgeryModule`。
- 关键前置条件：不是地图编辑态、不是时间线锁定态、当前 actor 必须是玩家且可控。
- 状态变更：角色移动、朝向、背包、肢体、需求、健康、目标锁定、地图地形 / 掉落、回合队列。
- 事件 / 返回值：`TimelineStepResult`，内部携带 `GameEvent` 列表与是否继续自动推进的信息。
- 副作用：`Main.Dispatch` 写日志、播放动画、切换当前目标、处理死亡、打开交互 UI。
- 刷新点：`Main.ApplyTimelineStep -> FinalizeTimelineStepUi -> FlushMap -> ProcessDirtyPanels`。

## AI 回合

- 入口：`Main.AdvanceTimelineAutoStep`，在 `_Process` 的自动推进窗口或 watch mode tick 中触发。
- 调用者：`Main._Process`、`WatchModeTick`。
- 被调者：`TimelineTurnManager.AdvanceAuto` -> `AIDispatcher.DecideAndExecuteAnyResult` -> `PerceptionBuilder` / `AwarenessModule` / `HealthBehaviorModule` / `FireBehaviorModule` / `TemperatureBehaviorModule` / `NeedBehaviorModule` / `IBrainModule.Decide` -> `ActionModule`。
- 关键前置条件：当前 actor 不为空；若当前 actor 是玩家，则必须处于旁观模式或玩家不可控。
- 状态变更：AI 角色感知状态、朝向、位移、攻击、施法、需求与健康状态；必要时推进世界回合。
- 事件 / 返回值：`TimelineStepResult.Events`，包含 AI 动作、天气、火焰、巢穴生成等事件。
- 副作用：玩家在 watch mode 下会被暂时挂上 `BrainId = "simple"`；`Main.Dispatch` 继续承担所有 UI 翻译。
- 刷新点：与玩家回合一致，最终回到 `FlushMap`、`TurnPanelModule.FlushIfDirty`、HUD 更新。

## 交互 / 对话 / 交易

- 入口：`Main.DoInteract`、面板物品右键、`InteractionModule.Execute` 产生的 `interaction` 事件。
- 调用者：`Main.OnCommand(:interact)`、地面/背包/宝箱面板。
- 被调者：`InteractionModule.GetAvailableTargets/GetInteractions/Execute`，然后 `Main.DispatchInteraction` 再分流到 `TradeUIModule.OpenTradeMenu` 或 `DialogUIModule.OpenDialog`。
- 关键前置条件：目标在邻近范围内且存在非战斗交互；对话目标 / 交易目标仍在 `GameState.Actors` 中。
- 状态变更：对话记忆、好感与 mood；交易会修改双方金币、背包与 shop slot；拾取 / 丢弃会修改地面堆叠。
- 事件 / 返回值：`GameEvent` 的 `Type = "interaction"`，`EffectType` 决定分流到 `trade` / `talk` / `tame` / 默认日志。
- 副作用：打开或关闭对话面板、交易面板；关闭一个交互 UI 时可能顺带关闭另一个，避免叠层。
- 刷新点：`TradeUIModule.Refresh`、`DialogUIModule.RefreshCurrentEntry`、`GroundPanel.Invalidate`、必要时 `FlushMap`。

## 会话 / 世界 / 存档

- 入口：菜单按钮、世界管理器按钮、设置流程的保存 / 读取动作、调试命令、楼梯交互。
- 调用者：`MenuModule`、`WorldManagerModule`、`SettingsFlowCoordinator`、`DebugModule`、`Main.DoEnterStairs`。
- 被调者：`GameSessionModule.NewGame/CreateWorld/StartWorldCharacter/LoadGame/LoadWorldCharacter/SaveGame/ChangeFloor`，下沉到 `MapGenModule`、`SaveModule`、`WorldStore`、`MapModule`。
- 关键前置条件：会话切换前先走 `PrepareSessionTransition`；世界与角色 ID 必须可解析；读取前先尝试 `SaveModule.TryReadSaveHeader`。
- 状态变更：`GameState.Reset`、世界 seed、玩家位置、天气、时间线、会话上下文、继续状态、world.json 与角色存档文件。
- 事件 / 返回值：`SaveLoadStatus`、`WorldManifest`、`WorldEntryInfo`、`WorldCharacterEntryInfo`、`ContinueTarget`。
- 副作用：读写文件系统；更新最近游玩世界与角色；创建世界目录与角色存档目录。
- 刷新点：`FinalizeSessionPanels`、`DoEnterGame`、`FlushMap`、世界浏览器 `RefreshWorldManagerContents`。

## 视野与渲染

- 入口：`Main.FlushMap`，以及 `_Process` 中的 `TileMapRenderModule.AdvanceAnimations`。
- 调用者：进入游戏、每次回合步进后、切楼层后、地图编辑操作后、某些 UI 操作后。
- 被调者：`TileMapRenderModule.SetEditorView`、`TileMapRenderModule.Flush`，内部消费 `GameState.World`、`FogOfWarTracker`、`ResAccess`、天气与实体渲染注册表。
- 关键前置条件：渲染器已 `Init`；如果处于地图编辑态，需要改用编辑相机中心和 hover cell。
- 状态变更：地图 TileLayer、记忆层、实体精灵、天气叠层、玩家动画引用、相机缩放、overlay 开关。
- 事件 / 返回值：无显式返回值；主要是 Godot 节点树更新与 `MarkUIDirty`。
- 副作用：`ResAccess.RegisterAnimatable`、播放玩家动画、更新天气屏幕特效、更新战斗浮字位置。
- 刷新点：`Main.MarkUIDirty` 标脏状态 / 技能条 / 背包 / 地面 / 回合面板；真正的面板刷新在下一帧 `_Process -> ProcessDirtyPanels`。

## 调试命令

- 入口：`Main.OnCommand` 中 `cmd.StartsWith('/')` 的分支。
- 调用者：输入栏或绑定到文本命令的动作。
- 被调者：`DebugModule.HandleCommand(cmd, _state, _session)`，内部再调用 `SpawnChest`、`SpawnEnemy`、`ToggleGodMode`、`session.ChangeFloor`、`session.ExportPresetScenario`、天气调试逻辑。
- 关键前置条件：玩家存在；命令需要有效参数时先做参数解析。
- 状态变更：世界掉落、敌人生成、玩家金币、无敌 buff、楼层、天气强制覆盖。
- 事件 / 返回值：`DebugModule.Result`，包含日志数组与 `NeedsFlush` 标记。
- 副作用：`DebugModule` 直接依赖 `GameSessionModule` 做楼层切换与预设导出，形成 `Core -> Module` 反向调用。
- 刷新点：`Main` 逐条写日志；若 `NeedsFlush` 为真则立即 `FlushMap`。
